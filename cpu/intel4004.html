▼ Instruction Reference & How To Use

▶ How to set your own inputs
1. Click a Sample Program button to load the program into ROM.
2. Click any register cell in the Registers table (R0, R1, R2…) — a prompt appears where you type your value in hex (0–F).
3. Press STEP or RUN. The program will use your new register values as inputs.
Alternatively: edit the second byte of the FIM instruction in the hex box (e.g. 20 53 → change 53 to set R0/R1), then hit LOAD again.
Data Movement
FIM Pp, $XYLoad immediate: R(2p)=X, R(2p+1)=Y. Used to set input values.20 XY
LD RrLoad register Rr into accumulator (A = Rr).Ar
XCH RrSwap accumulator with register Rr (A ↔ Rr). Used to store results.Br
LDM nLoad 4-bit immediate constant n into accumulator (A = n).Dn
SRC PpSend register pair Pp as RAM/ROM address for memory ops.2p+1
FIN PpFetch indirect: load byte from ROM address pointed to by P0 into Pp.3p
Arithmetic
ADD RrA = A + Rr + Carry. Sets Carry if result > 0xF.8r
SUB RrA = A + (~Rr) + (~Carry). Use CLC before SUB for correct subtraction (A − Rr).9r
INC RrIncrement register Rr by 1. Wraps 0xF → 0. Does not affect Carry.6r
IACIncrement accumulator (A = A + 1). Sets Carry on overflow.F2
DACDecrement accumulator (A = A − 1). Sets Carry if no borrow (A was > 0).F8
DAADecimal adjust accumulator for BCD arithmetic. Adds 6 if A>9 or Carry set.FB
ADMA = A + RAM[SRC] + Carry. Add from RAM cell pointed by SRC.EB
SBMA = A + (~RAM[SRC]) + (~Carry). Subtract RAM cell from accumulator.E8
Carry & Accumulator Flags
CLCClear Carry flag (Carry = 0). Required before ADD for clean addition, before SUB for correct subtraction.F1
STCSet Carry flag (Carry = 1).FA
CMCComplement (flip) Carry flag.F3
CMAComplement accumulator (A = ~A, bitwise NOT of all 4 bits).F4
CLBClear both accumulator and Carry (A = 0, Carry = 0).F0
TCCTransfer Carry to accumulator (A = Carry), then clear Carry. Used to propagate carry between nibbles.F7
TCSTransfer Carry subtract: A = 9 + Carry, Carry = 0. Used for BCD borrow correction.F9
Shifts
RALRotate accumulator left through Carry. Bit3→Carry, old Carry→Bit0. Effectively A×2.F5
RARRotate accumulator right through Carry. Bit0→Carry, old Carry→Bit3. Effectively A÷2.F6
Jumps & Branches
JUN addrUnconditional jump to 12-bit address. Opcode = 4x, next byte = low 8 bits of address.4x LL
JCN cond, addrConditional jump. Condition bits: bit2=jump if A=0 (AZ), bit1=jump if Carry set (CN), bit1=jump if Test (TN). bit3 inverts all.1c LL
ISZ Rr, addrIncrement Rr; if Rr ≠ 0 jump to addr. Useful for counted loops without needing LD+JCN.7r LL
JMS addrJump to subroutine (push PC, jump). Stack depth is 3 levels.5x LL
JIN PpJump indirect: PC low byte = register pair Pp value.3p+1
BBL nBranch back and load: return from subroutine (pop PC), set A = n.Cn
RAM Memory
WRMWrite accumulator to RAM cell at address set by SRC.E0
RDMRead RAM cell at SRC address into accumulator.E9
WR0–WR3Write accumulator to RAM status register 0–3.E4–E7
RD0–RD3Read RAM status register 0–3 into accumulator.EC–EF
WMPWrite accumulator to RAM output port (visible in Output Port panel).E1
WRRWrite accumulator to ROM output port (visible in ROM Port panel).E2
RDRRead ROM input port into accumulator.EA
DCLDesignate command line: selects which RAM chip is active based on A bits 0–2.FD
Other
NOPNo operation. Does nothing for 1 cycle. Often used as program end marker.00
KBPKeyboard process: converts single-bit keyboard scan value in A to key index (0–4, or 0xF for error).FC
▶ JCN condition byte quick reference
14 = jump if A=0 (AZ)  |  12 = jump if Carry set (CN)  |  11 = jump if Test pin set (TN)
1C = jump if A≠0 (ANZ)  |  1A = jump if Carry clear (CNZ)  |  19 = jump if Test clear (TNZ)
Condition bits: bit0=Test, bit1=Carry, bit2=A-zero, bit3=invert all.
